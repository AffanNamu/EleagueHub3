# Create consumable or non-consumable In-App Purchases

To offer In-App Purchases, add In-App Purchase information in App Store Connect. You can enter the metadata when you create your In-App Purchase or enter it later.

**Note:** It may take up to 1 hour for changes you make to product metadata to appear in the sandbox environment.

[Learn how to create In-App Purchases with the App Store Connect API.](https://developer.apple.com/documentation/appstoreconnectapi/app_store/in-app_purchase/in-app_purchases)

**Required role:** You must have the Account Holder, Admin, App Manager, Developer, or Marketing role to add and edit In-App Purchases. [View role permissions.](/help/app-store-connect/reference/account-management/role-permissions)

1.  In Apps, select the app you want to view.

2.  In the sidebar, under Monetization, click In-App Purchases.

3.  Click the add button (+).

    ![Create an In-App Purchase dialog with a Type pop-up menu, Reference Name and Product ID fields, and Cancel and Create buttons.](/help/app-store-connect/manage-in-app-purchases/create-consumable-or-non-consumable-in-app-purchases/images/InApp-AppDetails-menu-5_2x.png)

    ![Create an In-App Purchase dialog with a Type pop-up menu, Reference Name and Product ID fields, and Cancel and Create buttons.](/help/app-store-connect/manage-in-app-purchases/create-consumable-or-non-consumable-in-app-purchases/images/InApp-AppDetails-menu-5_2x.png)

4.  Select Consumable or Non-Consumable. [Learn about In-App Purchase types.](/help/app-store-connect/configure-in-app-purchase-settings/overview-for-configuring-in-app-purchases)

5.  Add the reference name and product ID, then click Create.
