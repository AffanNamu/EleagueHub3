# App privacy

| Property                 |     |     |     | Description                                                                                                                                                                                                                          |     |     |     |     |     |     |     |
|--------------------------|-----|-----|-----|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----|-----|-----|-----|-----|-----|-----|
| Privacy Policy URL       |     |     |     | A URL that links to your company’s privacy policy. This is required for all apps.                                                                                                                                                    |     |     |     |     |     |     |     |
| User Privacy Choices URL |     |     |     | A publicly accessible URL where users can learn more about their privacy choices for your app and how to manage them. For example, a webpage where users can access their data, request deletion, or make changes. This is optional. |     |     |     |     |     |     |     |
| Data Types               |     |     |     | The types of data collected by your app, either directly or through third-party partners.
