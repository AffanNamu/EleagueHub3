# App build statuses

The *build status* tells you immediately whether your build needs attention. The status applies to the build only, not the entire app.

- A red status indicator (![](/help/images/icons/status-red-icon_2x.png)) means that you need to perform some action or the build is expired.

- A yellow status indicator (![](/help/images/icons/status-yellow-icon_2x.png)) means that some process is ongoing, controlled either by you or by Apple.

- A green status indicator (![](/help/images/icons/status-green-icon_2x.png)) means the build is being tested in TestFlight.

You can view the [builds you upload and their file sizes](/help/app-store-connect/manage-builds/view-builds-and-metadata), [beta build status, and metrics](/help/app-store-connect/test-a-beta-version/view-build-status-and-metrics) under the TestFlight tab in App Store Connect.
