# NSPhotoLibraryUsageDescription

_Property List Key_

Platforms: iOS 6.0, iPadOS 6.0, macOS 10.14, visionOS 1.0

A message that tells people why the app is requesting access to their photo library.

### Discussion

If your app only adds assets to the photo library and does not read assets, use the  [NSPhotoLibraryAddUsageDescription](https://developer.apple.com/documentation/bundleresources/information-property-list/nsphotolibraryaddusagedescription) key instead.

> **Important:** This key is required if your app uses APIs that have read or write access to the user’s photo library.
